# Практическое задание 3Б — Справочник пользователей

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для выполнения запросов к JSONPlaceholder необходимо подключение к интернету.

## Результаты проверки
- Кнопка «Загрузить пользователей» выполняет GET-запрос к `/users` и отображает имя, email и город пользователей.
- Поиск фильтрует уже загруженный список по имени без учёта регистра и без дополнительных HTTP-запросов. При отсутствии совпадений отображается «Пользователи не найдены».
- Кнопка «Показать публикации» у каждого пользователя выполняет GET-запрос к `/posts?userId=ID` и показывает первые три публикации.
- Во время запросов отображается «Загрузка...». Кнопка загрузки пользователей блокируется на время запроса и снова активируется после его завершения.
- HTTP-ошибки и сетевые сбои обрабатываются с помощью `response.ok`, `try/catch/finally`; после ошибки запрос можно повторить.

Все изменения страницы выполняются через DOM, `createElement` и `textContent`. Данные не сохраняются в `localStorage`.
